# Архитектура Music Studio

## Компоненты

- `app/studio_server.py` — локальный HTTP-сервер на `127.0.0.1:7870`, библиотека, записи, создание треков и маршрутизация генерации.
- `app/ui/index.html` и CSS/JS — пользовательский интерфейс, создание песни, «Мой голос», карточки, обложки, плеер, история и избранное.
- `ACE-Step-1.5/` — **внешний** музыкальный движок. По запросу студии используется порт `7862`; может скачивать веса и требовать GPU.
- `Voice Engine/` — локальный конвейер Stem separation (Demucs), Seed-VC, анализ F0, контроль качества и мастеринг.
- `Voice Engine/seed-vc/` — внешняя база Seed-VC + наши дополнительные файлы из `overlays/seed-vc/`.
- `Voice Engine/alternatives/ApexSVC/` — внешний ApexSVC с патчем `overlays/apexsvc_custom.patch`. Пресет QA133 есть в `presets/`; его выполнение отдельно от текущего UI.
- `research/` — код экспериментальных проверок фонем, DiffSinger/OpenUtau, QA-отчётов и полного рэп-трека.

## Типовой путь генерации

1. UI отправляет описание, жанр, текст, голос и длительность локальному серверу.
2. `studio_sections.py`, `prompt_integrity85.py` и связанные модули готовят структурированный запрос.
3. ACE-Step синтезирует исходную музыку и вокал. Сохраняются отдельные оригинальные MP3 и мастер WAV.
4. Дополнительный голосовой маршрут (Seed-VC) использует выбранный пользователем референс, если пользователь включил перенос голоса. Отдельная обработка ApexSVC доступна через скрипты.
5. `studio_finisher34.py`, `studio_mix21.py` и проверки звука готовят итог. UI выводит карточку трека из локальной библиотеки.

## Состояние проверок

- Русская орфоэпия разрабатывается отдельно; проверены переходы фонем «Когда» (редукция безударного о), «Мне», «дождь», «мою».
- QA133 для короткого контрольного материала подтвердил лексическую точность автоматическим распознавателем, но **распознавание не подтверждает интонацию, ударение или совпадение тембра**.
- QA135: сохранён полный рэп с выбранным пресетом «Защита согласных», однако отдельные слова после переноса хуже распознаются. Публиковать модели как гарантированно готовые к коммерческому вокалу нельзя.
- QA136: подготовлены инструкции для низкого мужского припева; новая версия QA136 **не была аудиогенерирована** на момент подготовки репозитория.

## Принципы безопасности

Только локальный loopback-адрес. Репозиторий **не содержит** личных аудиофайлов и базы профилей. Модели и внешние зависимости загружаются из официальных источников, закреплённых по commit. Нельзя автоматически публиковать чужие вокальные данные или GitHub-токены.

Оригинальная программа остаётся в отдельных папках; установка с GitHub в новом каталоге не должна стирать пользовательские файлы.
