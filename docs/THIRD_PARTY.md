# Сторонние компоненты, веса и лицензии

**Важно:** репозиторий исходного HAPYCH Music Studio не содержит копии крупных сторонних AI-моделей, аудиобанков или исполняемых пакетов. Их требуется загрузить самостоятельно.

| Компонент | Проект | Лицензия / примечание |
|---|---|---|
| ACE-Step 1.5 | https://github.com/ACE-Step/ACE-Step-1.5 | MIT для исходного проекта; веса моделей могут иметь отдельные условия |
| Seed-VC | https://github.com/Plachtaa/seed-vc | GNU GPL (изучить конкретную версию в upstream); отдельные модели по собственным условиям |
| ApexSVC | https://github.com/HoppouAI/ApexSVC | AGPL-3.0-or-later; локальный патч в `overlays/apexsvc_custom.patch` распространяется на применимых условиях |
| Demucs | https://github.com/facebookresearch/demucs | Используется для выделения вокала, соблюдай upstream-лицензию |
| OpenUtau-LUNAI | OpenUtau-LUNAI fork/релиз, который использовался локально | Устанавливается отдельно; проверь лицензию форка |
| Keiro Revenant (LUNAI Project) | Сторонний голосовой банк | Использовался только для **некоммерческих** тестов; аудио/веса в GitHub не загружаются |

Коммиты основных upstream-проектов сохранены в `third_party_versions.json`. Установщик клонирует их по официальным адресам и применяет только локальные дополнения.

**Не предполагай, что право на запуск кода даёт право на публичную или коммерческую перепубликацию сторонних голосов, весов или обучающих датасетов.** Проверь правила каждой модели перед использованием.

Наличие данного приватного GitHub-репозитория не означает, что пользователю переданы права распространять персональные голосовые записи или лицензии на сторонние модели. В корне сознательно не указана универсальная лицензия, потому что права на компоненты различаются. Если потребуется открытая публикация, юридический статус каждого файла и патча надо проверить отдельно.
