# Диагностика

| Ошибка | Что проверять |
|---|---|
| `git clone` выдаёт 404 / Authentication failed | Репозиторий публичный. Проверь адрес `https://github.com/GUSTAVA009/hapych-music-studio.git`, доступ к GitHub, прокси и Git Credential Manager. |
| `uv` / `ffmpeg` не найдены | Установи программу, добавь в `PATH`, открой новый PowerShell. |
| Неверная папка установки | Клонируй именно в `%USERPROFILE%\Music Studio`; некоторые модули используют этот путь. |
| `Music Studio already exists` при установке из ZIP | Скачай новейший ZIP: официальный Git-клон теперь автоматически обновляется без потери личных файлов. Если существующая папка не содержит `.git`, сделай резервную копию и переименуй её; установщик не перезаписывает неизвестные каталоги. |
| `uv sync`: `No pyproject.toml found` после клонирования ACE-Step | Ошибка старого установщика: репозиторий скачивался через `--no-checkout` без рабочих файлов. Исправлено. В папке Music Studio выполни `git pull --ff-only` и заново запусти `scripts/Install-Windows.ps1`. Обновлённый установщик безопасно восстановит пустой checkout. Ничего вручную не удаляй. |
| `uv sync` не устанавливает CUDA / torch | Проверь Windows x64, драйвер GPU, свободное место, доступ к PyTorch index и конфликт версий. |
| Интерфейс не открывается | Проверь `http://127.0.0.1:7870/api/health` и файлы `app/music-studio-*.log`. |
| `Failed to fetch` при создании трека | Это **потеря HTTP-соединения** с Music Studio, а не точный код ошибки нейросети. Запусти `Diagnose.cmd`, проверь отдельно `/api/health`, `/api/diagnostics` и `/api/prepare`. Если сервер упал, проверь логи, память и порт 7870. После обновления API возвращает JSON 500 с идентификатором ошибки вместо внезапного обрыва запроса при внутренних исключениях. |
| Зависла «Инициализация ACE-Step» | У движка отдельный порт 7862. При первом запуске модели могут долго скачиваться. В старой версии был принудительный CUDA GPU 0 и LM 1.7B на любом ПК. В новой версии используется автоматический подбор настроек ACE-Step, проверка фонового процесса и информативная ошибка при аварийном завершении. |
| Неправильно показывает RTX 4060 | Старый UI содержал жёстко зашитую модель видеокарты. Исправлено: UI отображает доступность ACE-Step без выдуманного названия GPU. |
| `Studio` уже работает, но запуск говорит, что сервер не готов | В старом `Start-MusicStudio.ps1` готовность веб-сервера ошибочно зависела от полной инициализации моделей. Исправлено: сервер запускается один раз, а загрузка ACE-Step отображается отдельно. |
| ACE-Step не запускается | Проверь `ACE-Step-1.5\.venv\Scripts\acestep.exe`, порт `7862` и доступность pretrained-моделей. |
| GPU out of memory | Закрой игры и иные GPU-задачи; используй offload/уменьши пакет/выбери CPU-режим, где поддерживается. |
| Seed-VC сообщает о отсутствующем checkpoint | До голосового переноса скачай модели по документации официального Seed-VC. |
| ApexSVC не находит pretrained weights | Выполни установку с `-Full -DownloadModels`; проверь доступность источников и лицензии. |
| Ошибочный русский акцент или ударение | Проверь исходный вокал до voice-conversion, фонемы, ударения и F0. ASR сам по себе недостаточен. |
| Вокал «режется» | Проверь длину чанков, стыки, RMS и дрейф F0; не склеивай с исходным чужим певцом. |
| UI отображается слишком мелко | Проверь масштаб браузера (Ctrl+0) и активные файлы `app/ui/`, не старые QA-превью. |

Репозиторий не включает свои личные базы, ключи, токены и веса. Не прикладывай их к GitHub Issues. Для поиска ошибок лучше прислать обезличенный лог и версии компонентов.
