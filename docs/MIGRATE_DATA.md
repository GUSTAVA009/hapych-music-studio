# Перенос личных файлов на новый компьютер — БЕЗ GitHub

**Внимание:** личные WAV, песни, модели и профили не загружались в репозиторий. GitHub предназначен для программного кода.

После установки программы переноси только собственные файлы по защищённому носителю (например, внешний SSD или локальная сеть). Закрой Music Studio на обоих ПК перед копированием.

Рекомендуемые каталоги из старого `%USERPROFILE%\Music Studio`:

| Папка | Что внутри |
|---|---|
| `Мой голос` | Записи микрофона и образцы для переноса тембра |
| `Мои треки` | Созданные MP3, карточки и метаданные |
| `Мастер WAV` | Несжатые мастера |
| `Исходные версии` | История исходных генераций |
| `Voice Profiles` | Локальная база профилей и права владельца записей |
| `Training Runs` | Результаты обучения, если нужны |
| `Voice Engine\seed-vc\runs` | Обученные личные checkpoints, если они имеются |
| `app\models` | Дополнительные пользовательские модели, если они имеются |

Пример копирования локально через временный диск `E:\MusicStudioBackup` (выполняется **на старом ПК**):

~~~powershell
robocopy "$env:USERPROFILE\Music Studio\Мой голос" "E:\MusicStudioBackup\Мой голос" /E
robocopy "$env:USERPROFILE\Music Studio\Мои треки" "E:\MusicStudioBackup\Мои треки" /E
robocopy "$env:USERPROFILE\Music Studio\Мастер WAV" "E:\MusicStudioBackup\Мастер WAV" /E
~~~

На новом ПК скопируй содержимое обратно через Проводник Windows после установки программы. **Не** копируй наугад `.venv`, `Cache`, `node_modules`, `.git` и конфигурации секретов — их нужно переустановить либо адаптировать.

Никому не отправляй профили голоса, личные checkpoint-файлы или записи без явного согласия владельца. Проверяй абсолютные пути в старых `.track.json`, если UI не видит старую библиотеку.
