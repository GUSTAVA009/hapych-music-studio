# Как удалить HAPYCH Music Studio, установленную до появления деинсталлятора

Эта инструкция предназначена для пользователей старого выпуска **HAPYCH Music Studio для Windows 10/11**, у которых **нет иконки программы, пункта в списке установленных приложений и файла `Uninstall.cmd`**.

**Не нужно заново ставить музыку, скачивать десятки гигабайт моделей или удалять свои треки.**

## Способ 1 — автоматически добавить удаление в уже установленную программу (рекомендуется)

1. Скачайте **последний исходный ZIP** из [официального GitHub](https://github.com/GUSTAVA009/hapych-music-studio/archive/refs/heads/main.zip).
2. В Проводнике Windows нажмите по архиву правой кнопкой → **Извлечь всё**. Не запускайте `.cmd` непосредственно из ZIP.
3. Откройте новую извлечённую папку и дважды щёлкните **`Enable-Uninstall-Existing.cmd`**.
4. Утилита найдёт существующую папку **`%USERPROFILE%\Music Studio`**, проверит принадлежность проекта и добавит необходимые компоненты для управления установкой. Она не запускает генерацию, не скачивает AI-модели, не удаляет треки и не затрагивает настройки приложения. Для **старого Git-установщика** она также выполняет только безопасное обновление официальных исходников (`git pull --ff-only`). Если в коде есть пользовательские изменения, обновление будет остановлено. Для **старого ZIP-установщика** она добавляет только отсутствующие вспомогательные файлы, ничего не перезаписывая.
5. Когда появится сообщение **`[PASS] Existing installation can be removed through Windows Installed apps.`**, закройте окно.

После этого появятся:
- иконка HAPYCH Music Studio на **Рабочем столе**;
- ярлыки запуска и удаления в меню **Пуск**;
- **Параметры → Приложения → Установленные приложения → HAPYCH Music Studio → Удалить** (в Windows 10: «Приложения и возможности»);
- `%USERPROFILE%\Music Studio\Uninstall.cmd`.

## Способ 2 — удалить программу через Windows после подключения деинсталлятора

1. Сохраните незавершённую работу и дождитесь окончания генерации треков.
2. Откройте **Параметры Windows → Приложения → Установленные приложения**.
3. Выберите **HAPYCH Music Studio → Удалить**. Можно также запустить `Uninstall.cmd` в папке программы.
4. В открывшемся окне выберите:
   - **`1` — удалить студию и скачанные модели, сохранить личное.** Личные аудиозаписи, песни, профили и найденные пользовательские файлы переместятся в резервную папку **Документы → HAPYCH Music Studio Backups → дата и время**. **Это рекомендуемый вариант.**
   - **`2` — удалить всё, в том числе личные данные.** Этот режим необратим и требует **отдельного подтверждения**.
   - **`0` — отмена**.
5. Подтвердите выбор, введя **`UNINSTALL`**; для режима 2 необходимо дополнительно ввести **`DELETE ALL`**.
6. После удаления проверьте резервную папку в «Документах», прежде чем самостоятельно очищать резервные копии.

**Ограничения:** мастер остановится, если обнаружит активную генерацию, посторонний процесс, изменённые файлы исходников, символические ссылки в папке установки или несоответствующий маркер. Эти защитные проверки нельзя обходить без отдельного анализа. Пользовательские модели, сохранённые внутри папок сторонних движков, перед удалением рекомендуется скопировать отдельно.

## Способ 3 — вручную, если старая установка неполная и помощник отказывается работать

Это **резервный способ**. Он не создаёт штатного пункта Windows и требует особой осторожности.

1. Нажмите **Win + R**, вставьте **`%USERPROFILE%\Music Studio`** и нажмите Enter.
2. Если папка не существует, ничего не удаляйте: вероятно, приложение было установлено в другой каталог. Найдите **реальную папку программы** по её ярлыку или старому пути запуска.
3. **До удаления** скопируйте все пользовательские данные в безопасное место вне папки Music Studio: `Мои треки`, `Мой голос`, `Voice Profiles`, `Мастер WAV`, `Исходные версии`, `Sound Library`, `Exports`, `Training Runs` и любые собственные записи или обученные модели внутри `ACE-Step-1.5`, `Voice Engine` и других папок. При достаточном месте безопаснее сначала скопировать всю папку `Music Studio`.
4. Откройте несколько сохранённых аудиофайлов из резервной копии, убедитесь, что данные действительно скопированы.
5. Завершите генерацию и закройте приложение. Убедитесь, что в фоновом режиме не работает сервер Music Studio или ACE-Step. **Не завершайте все процессы Python подряд**: они могут относиться к другим приложениям.
6. Только после проверки резервной копии удалите **точно папку программы `Music Studio`** через Проводник Windows. Не удаляйте родительский каталог пользователя, другие проекты или глобальные папки с моделями.
7. Если старых ярлыков нет, дополнительных действий в «Установленных приложениях» не требуется. Если ярлыки остались, удалите только ярлыки HAPYCH Music Studio.

**Общие компоненты Git, uv, Python, FFmpeg и сторонние кэши моделей автоматически не удаляются**, поскольку они могут использоваться другими программами. Не чистите `%USERPROFILE%\.cache`, общие Python-среды и системные каталоги ради удаления этой студии.

## Частые проблемы

- **«Installed Music Studio directory not found»** — стандартная папка `%USERPROFILE%\Music Studio` отсутствует. Используйте ручную инструкцию и проверьте фактическое расположение.
- **«Not the official Git repository» / локальные изменения** — автоматическое обновление не затронет файлы. Сначала сохраните собственные изменения; для удаления можно выбрать резервный способ.
- **«File is customized/older; refusing overwrite»** — в старой ZIP-копии уже есть файл с тем же именем, но другим содержимым. Ничего не перезаписывается: сохраните существующие файлы и обратитесь за инструкцией по совместимости.
- **«Install safety marker is missing»** — запускается новый деинсталлятор в папке, не зарегистрированной новым мастером. Сначала выполните **`Enable-Uninstall-Existing.cmd`**.
- **Программа создаёт музыку прямо сейчас** — сначала дождитесь завершения задания, затем повторите удаление.

Не используйте старый `Install.cmd` только для удаления: он предназначен для установки/обновления и может начать скачивать компоненты.

**Техническая проверка:** [Windows-тест миграции старой установки](../tests/Existing-Install-Uninstall.ps1) выполняет сценарии регистрации старой ZIP-установки, повторного запуска, сохранения песен и моделей, отказа при конфликтах и удаления с резервным копированием. Реальные пользовательские файлы тест не затрагивает.
