# Public distribution and third-party model licensing

HAPYCH Music Studio is free to clone and install from the public GitHub repository. The root LICENSE covers the project's original sources only.

External repositories and pretrained model weights are not bundled in our source ZIP. Official sources used by the installer:

- ACE-Step 1.5: MIT source license. Model weights may have separate restrictions.
- Seed-VC: GPL-3.0, including the upstream-derived portions of our overlays.
- ApexSVC: AGPL-3.0-or-later; compatibility patches retain upstream terms.
- Demucs and other Python libraries: upstream licenses in their distributions.
- OpenUtau / DiffSinger voicebanks: intentionally not included, require separate licenses.
- Personal training files, microphone WAVs, user libraries, checkpoints, API keys, credentials: intentionally not included.

Public GitHub distribution does NOT imply a right to clone or impersonate another person's voice without permission. Review individual model licenses before commercial use.
